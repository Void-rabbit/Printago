API Documentation

This page provides documentation for the 3D Print Farm Manager API. All API endpoints require an X-API-Key header for authentication.

Example API Key Header: X-API-Key: your_secret_api_key

General Information

  • Base URL: /api
  • Authentication: Required for all endpoints. Provide your API key in the X-API-Key request header.
  • Response Format: JSON
  • Error Responses: Errors are returned in JSON format, typically with an {"error": "message"} structure. Common HTTP status codes are used (e.g., 400 for bad request, 401 for unauthorized, 404 for not found).

Parts API

Endpoints for managing 3D printing parts.

GET /api/parts

  • Method: GET
  • Description: Returns a list of all parts.
  • Authentication: Required.
  • Response: 200 OK - Array of part objects.

GET /api/parts/<part_id>

  • Method: GET
  • Description: Returns details of a specific part.
  • Authentication: Required.
  • Path Parameters:
    • part_id (string): The unique identifier for the part.
  • Response: 200 OK - Part object. 404 Not Found if part does not exist.

POST /api/parts

  • Method: POST
  • Description: Creates a new part.
  • Authentication: Required.
  • Request Body (JSON): 
    {
    "name": "New Part Name",
    "material": "PLA",
    "filename": "new_part.stl",
    "print_settings": "Layer height: 0.2mm, Infill: 20%"
}
  • Required Fields in Body: name, material. Optional: filename, print_settings.
  • Response: 201 Created - The newly created part object. 400 Bad Request for invalid input.

PUT /api/parts/<part_id>

  • Method: PUT
  • Description: Updates an existing part.
  • Authentication: Required.
  • Path Parameters:
    • part_id (string): The unique identifier for the part to update.
  • Request Body (JSON): Contains fields to update. 
    {
    "name": "Updated Part Name",
    "material": "PETG",
    "print_settings": "Layer height: 0.15mm, Infill: 50%"
}
  • Response: 200 OK - The updated part object. 400 Bad Request for invalid input. 404 Not Found if part does not exist.

DELETE /api/parts/<part_id>

  • Method: DELETE
  • Description: Deletes a part.
  • Authentication: Required.
  • Path Parameters:
    • part_id (string): The unique identifier for the part to delete.
  • Response: 200 OK - Success message (e.g., {"message": "Part deleted successfully"}). 404 Not Found if part does not exist.

Printers API

Endpoints for accessing printer information.

GET /api/printers

  • Method: GET
  • Description: Returns a list of all printers.
  • Authentication: Required.
  • Response: 200 OK - Array of printer objects.

GET /api/printers/<printer_id>

  • Method: GET
  • Description: Returns details of a specific printer, including mocked live status.
  • Authentication: Required.
  • Path Parameters:
    • printer_id (string): The unique identifier for the printer.
  • Response: 200 OK - Printer object with a live_status field. 404 Not Found if printer does not exist.

Note: CUD operations for Printers are not yet implemented in the API.

Print Jobs API

Endpoints for accessing print job information.

GET /api/print_jobs

  • Method: GET
  • Description: Returns a list of all print jobs, sorted by priority and creation date.
  • Authentication: Required.
  • Response: 200 OK - Array of print job objects.

GET /api/print_jobs/<job_id>

  • Method: GET
  • Description: Returns details of a specific print job.
  • Authentication: Required.
  • Path Parameters:
    • job_id (string): The unique identifier for the print job.
  • Response: 200 OK - Print job object. 404 Not Found if job does not exist.

Note: CUD operations for Print Jobs are not yet implemented in the API.
